# 🏗️ Архитектура Neurotask - AI Agents for Business

## Обзор системы

Neurotask - AI Agents for Business - это микросервисное приложение для управления Telegram ботами с интеграцией AI и календаря.

## 🏛️ Архитектурные принципы

- **Микросервисная архитектура** - каждый сервис отвечает за свою область
- **API-first подход** - все сервисы взаимодействуют через REST API
- **Event-driven** - асинхронная обработка событий
- **Stateless** - сервисы не хранят состояние между запросами
- **Horizontal scaling** - возможность горизонтального масштабирования

## 🔧 Основные компоненты

### 1. Frontend (React)
- **Порт**: 5173
- **Технологии**: React 18, Vite, Tailwind CSS
- **Функции**: 
  - Управление Telegram ботами
  - Настройка AI провайдеров
  - Интеграция с календарем
  - Мониторинг и статистика

### 2. Main Server
- **Порт**: 3001
- **Технологии**: Express.js, Session management
- **Функции**:
  - Аутентификация и авторизация
  - Проксирование запросов к микросервисам
  - Управление сессиями
  - CSRF защита

### 3. Database Service
- **Порт**: 3012
- **Технологии**: Express.js, MongoDB, Mongoose
- **Функции**:
  - Управление пользователями
  - Хранение настроек AI
  - История чатов
  - Управление командами

### 4. Cache Service
- **Порт**: 3013
- **Технологии**: Redis
- **Функции**:
  - Кэширование API ответов
  - Хранение сессий

### 5. Balance Service
- **Порт**: 3002
- **Технологии**: Express.js, MongoDB
- **Функции**:
  - Управление балансом токенов
  - История транзакций

### 6. AI Gateway Service
- **Порт**: 3014
- **Технологии**: Express.js
- **Функции**:

  - Балансировка нагрузки

### 7. AI Services

## 🔄 Потоки данных

### Аутентификация
1. Пользователь вводит логин/пароль
2. Main Server проверяет учетные данные через Database Service
3. Создается сессия и CSRF токен
4. Сессия сохраняется в Cache Service

### AI запрос
1. Frontend отправляет запрос к Main Server
2. Main Server проверяет авторизацию
3. Запрос проксируется к AI Gateway Service
4. AI Gateway выбирает подходящий AI Service
5. AI Service обрабатывает запрос
6. Balance Service списывает токены
7. Ответ возвращается через цепочку сервисов

### Telegram Bot
1. Telegram Bot Service получает сообщение
2. Запрос к AI Service через AI Gateway
3. Ответ отправляется пользователю
4. История сохраняется в Database Service

## 🚀 Масштабирование

### Горизонтальное масштабирование
- Каждый сервис может быть запущен в нескольких экземплярах
- Load balancer распределяет нагрузку
- Redis кластер для кэширования
- MongoDB replica set для базы данных

### Вертикальное масштабирование
- Увеличение ресурсов для каждого сервиса
- Оптимизация кода и запросов
- Мониторинг производительности

## 🔒 Безопасность

### Аутентификация
- Session-based аутентификация
- CSRF токены для защиты от атак
- Валидация входных данных

### Авторизация
- Role-based access control (RBAC)
- Проверка прав доступа к ресурсам
- API ключи для межсервисного взаимодействия

### Шифрование
- HTTPS для всех внешних соединений
- Шифрование токенов в базе данных
- Безопасное хранение паролей (bcrypt)
