# Скрипты миграции системы команд

Этот каталог содержит скрипты для миграции существующих данных в новую систему команд.

## Файлы

### 1. `migrateTeams.js` - Основной скрипт миграции
**Назначение**: Миграция существующих пользователей в систему команд

**Что делает**:
- Создает команду по умолчанию "Основная команда"
- Назначает первого пользователя владельцем команды
- Добавляет всех остальных пользователей как участников команды
- Создает записи TeamMember для каждого пользователя
- Устанавливает базовые права доступа

**Запуск**:
```bash
npm run migrate
```

### 2. `testMigration.js` - Тестирование миграции
**Назначение**: Тестирование миграции на тестовых данных

**Что делает**:
- Создает тестовых пользователей
- Запускает миграцию
- Проверяет корректность результатов
- Использует тестовую базу данных

**Запуск**:
```bash
npm run migrate:test
```

### 3. `checkMigration.js` - Проверка результатов
**Назначение**: Проверка результатов миграции

**Что делает**:
- Проверяет созданные команды
- Анализирует пользователей и их роли
- Проверяет участников команд
- Выполняет проверку целостности данных

**Запуск**:
```bash
npm run migrate:check
```

## Процесс миграции

### Шаг 1: Подготовка
1. Убедитесь, что MongoDB запущена
2. Проверьте переменные окружения в `.env` файле
3. Сделайте резервную копию базы данных

### Шаг 2: Тестирование
1. Запустите тестовую миграцию: `npm run migrate:test`
2. Проверьте результаты: `npm run migrate:check`
3. Убедитесь, что все работает корректно

### Шаг 3: Продакшн миграция
1. Запустите основную миграцию: `npm run migrate`
2. Проверьте результаты: `npm run migrate:check`
3. Убедитесь, что все пользователи добавлены в команды

## Переменные окружения

```env
# Основная база данных
MONGODB_URI=mongodb://localhost:27017/telegram_bot

# Тестовая база данных (для testMigration.js)
MONGODB_TEST_URI=mongodb://localhost:27017/telegram_bot_test
```

## Структура данных после миграции

### Команда по умолчанию
- **Название**: "Основная команда"
- **Описание**: "Основная команда для всех пользователей"
- **Владелец**: Первый пользователь в системе
- **Настройки**: Стандартные настройки с возможностью расширения

### Пользователи
- **Первый пользователь**: Роль `owner`, полные права
- **Остальные пользователи**: Роль `member`, базовые права

### Права доступа
- **Owner**: Все права (управление командой, участниками, задачами, ботами, AI настройками)
- **Member**: Базовые права (просмотр, создание и редактирование задач, просмотр ботов и AI настроек)

## Безопасность

⚠️ **Важно**: 
- Всегда делайте резервную копию перед миграцией
- Сначала тестируйте на тестовых данных
- Проверяйте результаты после миграции
- Миграция необратима - будьте осторожны

## Устранение неполадок

### Ошибка подключения к базе данных
- Проверьте, что MongoDB запущена
- Проверьте переменные окружения
- Убедитесь, что у вас есть права доступа

### Ошибки валидации
- Проверьте, что все обязательные поля заполнены
- Убедитесь, что модели соответствуют схеме
- Проверьте, что все зависимости установлены

### Проблемы с правами доступа
- Проверьте, что пользователи имеют корректные роли
- Убедитесь, что TeamMember записи созданы корректно
- Проверьте настройки permissions
